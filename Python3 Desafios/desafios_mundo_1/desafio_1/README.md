# Boas Vindas ao Usuário

Programa Python simples para receber o nome de um usuário e exibir uma mensagem de boas-vindas.

## Descrição

Este script solicita ao usuário que digite o nome e, em seguida, imprime:

`Olá, <nome>! Seja bem-vindo(a)!`

É um exercício introdutório de entrada e saída em Python.

## Arquivo

- `boas_vindas_usuario.py`

## Como executar

1. Vá para a pasta onde o arquivo está:
   ```bash
   cd "Python3 Desafios/desafios_mundo_1/desafio_1"
   ```
2. Execute:
   ```bash
   python3 boas_vindas_usuario.py
   ```

## Funcionamento

- `input("Digite seu nome: ")` lê o nome.
- Concatena com saudação.
- `print(mensagem)` exibe na tela.

## Exemplo

```
Digite seu nome: João
Olá, João! Seja bem-vindo(a)!
```

## Requisitos

- Python 3.x

## Observações

- Não há validação de entrada no exercício (aceita qualquer texto).
- Ideal para iniciantes aprenderem `input` e `print`.
