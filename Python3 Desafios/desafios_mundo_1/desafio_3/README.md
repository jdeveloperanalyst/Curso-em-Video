# Desafio 3 - Soma entre Números

Este script solicita dois valores inteiros ao usuário e exibe a soma.

## Como usar

1. Execute o script com Python 3:
    ```bash
    python3 "Python3 Desafios/desafios_mundo_1/desafio_3/soma_entre_numeros.py"
    ```
2. Informe os valores solicitados:
    - Primeiro número (inteiro)
    - Segundo número (inteiro)

## Comportamento

- O script converte as entradas para `int`.
- Imprime o resultado da soma.
- Entrada inválida (texto não numérico) gera `ValueError`.

## Exemplo

```
Digite o primeiro número: 7
Digite o segundo número: 8
A soma entre 7 e 8 é 15
```
